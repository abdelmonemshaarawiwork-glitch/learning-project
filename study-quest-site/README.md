# Study Quest — website + private AI study planner

Live: **https://study-quest-journey.netlify.app** (Arabic: `/ar/`)
Private planner: **https://study-quest-journey.netlify.app/agent/** (Arabic: `/ar/agent/`) — password protected.

## What's here

| Path | What it is |
|---|---|
| `index.html`, `ar/index.html` | Information pages (generated by `build.py`; all copy lives there) |
| `agent/`, `ar/agent/` + `assets/agent.js` | The private study planner page (generated by `build.py`) |
| `netlify/functions/agent-run-background.mts` | Background function (up to 15 min): runs one planner turn with Claude and stores progress/results |
| `netlify/functions/agent.mts` | Fast API: password check, progress, saved plans |
| `netlify/lib/` | Claude call (structured JSON, streamed, fallback model), storage (Netlify Blobs), auth, schema |
| `dev-server.mts` | Local server with a stand-in for Claude: `npm install && npm run dev` → http://localhost:8888, password `local-dev-password` |
| `tests/` | `npm test` (server logic) · `npm run test:e2e` (browser flow; needs `npm run dev` running on port 8899 or `BASE=…`) |

## How the planner works

Netlify stops ordinary functions after ~30 seconds (measured), and a careful plan can take longer, so each message runs in a
**background function**. It saves progress (a live preview of stages and levels) and the final answer to Netlify Blobs; the page
checks every 1.5 s, and resumes waiting if you reload. Conversations and plans are saved, so they're available on any device.

## Settings (Netlify → Site configuration → Environment variables)

| Variable | Required | Notes |
|---|---|---|
| `AGENT_PASSWORD` | yes | The password for the planner page. Use a long one. |
| `ANTHROPIC_API_KEY` | yes | Your Claude API key (secret). |
| `ANTHROPIC_MODEL` | no | Default `claude-opus-5-5`. |
| `ANTHROPIC_EFFORT` | no | `low` / `medium` (default) / `high`. |
| `AGENT_DAILY_LIMIT` | no | Messages per day (default 60) — a safety cap on cost. |

Ten wrong passwords from one address lock it out for the rest of the hour. Functions read new values after the next deploy.

## Deploy

`netlify.toml` builds the pages, copies only the public files into `public/`, and bundles the functions.
With the Netlify CLI from this folder: `npx netlify-cli deploy --build --prod`.
